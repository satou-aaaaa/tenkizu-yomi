# 天気図よみ

等圧線と前線がかかれた天気図を読んで、季節・風の強さ・風向き・天気を当てる、1日5問のクイズ。

- 遊ぶ: https://satou-aaaaa.github.io/tenkizu-yomi/
- 今日の5問（季節・風の強さ・風向き・天気・天気）はだれでも同じで1日1回。答えるたびに、天気図のどこを見ればよいかの説明が出ます。
- 上級（風向きは8方位から・説明は最後にまとめて）、練習、何問続けて読めるかの「とことん」（まちがえても終わらず「ここで降りる」まで続く・自己ベストを残す）、種類ごとに正解を数える「読めた数」があります。時間制限はありません。
- 答えたあと、天気図に風の矢印（長いほど強い）が重なり、聞いた地点の風と天気が絵で分かります。
- まちがえた問題は、次の日から「復習」で解き直せます（正解すると消え、まちがえるとまた次の日に出ます）。
- 実績（腕前・集める・続ける）、遊んだ日のカレンダー、取りこぼした過去7日の5問をあとから遊ぶ機能があります（あとから遊んだ日は連続の日には数えません）。
- 天気図は、本物の天気図によくある形（冬の西高東低・夏の太平洋高気圧・梅雨前線・春と秋の移動性高気圧と温帯低気圧）をもとに、毎日作る架空のものです。実際の天気ではありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（地名は入りません）。

## 天気図の決まり（出どころ）

- 風は、気圧の高い方から低い方へ、等圧線に対して斜めに吹き込みます（北半球では高気圧から時計回りに吹き出し、低気圧へ反時計回りに吹き込む）。等圧線がこんでいる所ほど風が強い。
  - 気象庁「天気図の見方」などの説明、防衛省の気象コラム（https://www.mod.go.jp/ ）、ウェザーニュースの解説（https://weathernews.jp/ ）と同じ向きになるよう、`gen.js` の `wind` で等圧線に沿う向きから低気圧の側へ30度まわしています（QA が東西南北の向きを見ます）。
- 冬型（西高東低）のとき、日本海側は雪、太平洋側は晴れ。前線や低気圧の近くは雨、高気圧の中は晴れ。
- 日本の形は [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`（国土交通省「国土数値情報（行政区域データ）」をもとにしたもの）を、都道府県リレーと同じ方法で間引いた `japan.js` です。
